The recycle bin keeps the resources you have deleted, and you can restore any of them.

<Image src={recycleBinImage} alt="The HERITRACE recycle bin, listing deleted resources" width={800} height={600} />

### Finding a deleted resource

The recycle bin looks like the catalogue:

-   **Categories** (left): the types of the deleted resources.
-   **Resources** (right): the deleted resources of the selected category, the most recently deleted first. You can reverse the order to start from the oldest.

### Restoring a resource

Each deleted resource has two buttons:

-   **View last version** shows the resource as it was just before it was deleted.
-   **Restore** brings the resource back to the collection and removes it from the recycle bin.
