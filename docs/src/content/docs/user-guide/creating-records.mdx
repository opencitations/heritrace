HERITRACE guides you through adding a resource and checks what you enter at each step.

<Image src={creationImage} alt="HERITRACE page for adding a resource" width={800} height={600} />

### Adding a resource

1.  **Choose the type**: on the **Add** page, choose the type of resource you want to add. The form then shows the fields of that type.

2.  **Fill in the fields**: complete at least the required fields. HERITRACE points out a value that does not fit while you type, so you can correct it at once.

3.  **Link other resources**: some fields link to another resource, such as an author or a journal. Search for a resource already in the collection, or create a new one. While you fill in the form, HERITRACE warns you when a resource with the same details already exists.

4.  **Save**: once the form shows no more problems, click **Add**.
