Adding new records in HERITRACE follows a guided process with validation at each step.

<Image src={creationImage} alt="HERITRACE creation interface" width={800} height={600} />

### Creation workflow

1.  **Select Entity Type**: Start by choosing the type of entity you want to create from the dropdown on the "Add" page. The form will dynamically display the relevant metadata fields for that type.

2.  **Fill in Metadata**: Complete the required fields. You will receive real-time validation feedback to help you enter correct information.

3.  **Link to Existing Entities**: Fields that link to another entity let you search the collection and pick an existing entity, or create a new one. While you fill in the record, HERITRACE warns you if the values match an entity that already exists.

4.  **Save the Record**: Once you have filled in the information and resolved any validation issues, save the new record.
