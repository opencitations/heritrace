HERITRACE keeps every version of each resource, from its creation onwards.

### The time machine

The time machine of a resource lists its versions. A new version is added each time someone creates, changes or deletes the resource.

<Image src={timeMachineImage} alt="The HERITRACE time machine" width={800} height={600} />

For each version, the time machine shows:
-   when the change was made;
-   **Responsible agent**: who made it, identified by their ORCID iD;
-   **Primary source**: the source the change was based on, when the person who made it gave one;
-   **Additions** and **Deletions**: what was added and what was removed.

### Viewing and restoring an earlier version

You can look at a version before deciding whether to restore it.

**Step 1: open the version**

In the time machine, find the version you want and click **View version**.

<Image src={viewVersionImage} alt="A version in the time machine, with the View version button highlighted" width={800} height={600} />

**Step 2: check it and restore it**

The page of the version shows the resource exactly as it was at that moment, together with the resources it was linked to.

<Image src={versionImage} alt="Page of an earlier version of a resource" width={800} height={600} />

If this is the state you want, click **Restore this version**.

Restoring a version can affect linked resources too. Changes they received in the same edits are undone as well, while changes made to them separately remain.

### Deleted resources

A deleted resource stays in the [recycle bin](../recycle-bin), where you can look at it, view its history and restore it.
